# CS-250-Software-Development-Lifecycle
Contains coursework and portfolio artifacts from CS 250: Software Development Lifecycle at SNHU
## Course Overview

CS 250 focused on the software development life cycle (SDLC) and the use of Agile methodologies in software development. Throughout the course, I worked through different roles on a Scrum team while developing a project for SNHU Travel. This included working from the perspectives of the Product Owner, tester, developer, and Scrum Master.

The course emphasized translating client needs into user stories, developing and testing software in increments, responding to changing requirements, and using communication and collaboration throughout the development process.
